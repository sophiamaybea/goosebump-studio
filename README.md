# Goosebump Studio

Static front end for the Goosebump Engine studio.

The original stays locked. This page drafts an allowlisted mix plan and lets a human mark what the body did. It does not render new audio by itself.

## Deploy

This is a static site. No build step.

- Vercel: import this repo. Framework preset Other. Output is the repo root.
- Netlify: publish directory is the repo root.
- GitHub Pages: Settings, Pages, deploy from branch `main`, folder `/` (root).

Private OpenClaw memory is not in this repository.
